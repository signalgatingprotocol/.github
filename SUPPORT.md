# Support

- **Questions and design discussion:** use
  [GitHub Discussions](https://github.com/orgs/signalgatingprotocol/discussions).
- **Implementation bugs:** open an issue in the repository containing the code.
- **Protocol changes:** use the
  [`community` RFC process](https://github.com/signalgatingprotocol/community/tree/main/rfcs).
- **Security vulnerabilities:** follow the private process in
  [SECURITY.md](./SECURITY.md).

Include a minimal reproduction, exact version or commit, expected behavior, and
actual behavior when reporting a bug.
