# Signal Gating Protocol organization defaults

This repository controls the public organization profile and the default
community health files inherited by repositories that do not define their own.

- [`profile/README.md`](./profile/README.md) is the organization landing page.
- [`CONTRIBUTING.md`](./CONTRIBUTING.md) routes code and protocol contributions.
- [`SECURITY.md`](./SECURITY.md) defines private vulnerability reporting.
- [`SUPPORT.md`](./SUPPORT.md) routes questions, bugs, and design proposals.
- [`.github/`](./.github/) contains default issue and pull request templates.

Protocol governance and RFCs live in the
[`community`](https://github.com/signalgatingprotocol/community) repository.
